## Key Captures

### ZOE's Self-Verification Loop Shipped (PRs #2853–#2855, #2862–#2863)

**Category:** ZOE Core / Architecture

Today's most significant arc: ZOE can now catch its own mistakes before they ship.

- **verify-replan (#2853):** After producing a research doc or any autonomous output, ZOE runs a judge step that checks for incompleteness. If partial → it replans and tries again. No more silently-partial docs.
- **Step-level tracing (#2854):** When a run fails, you can now see WHERE it died — not just "it failed," but which step, which tool, what the input was. No new dependency.
- **Golden-eval harness (#2855):** A regression test for ZOE's own prompts. Any proposed prompt change runs against a "golden" set of expected behaviors before shipping. Catches the case where a tuning change makes ZOE worse in a subtle way.
- **Cross-family critics via Codex (#2862, #2863):** Instead of ZOE criticizing its own work (same-family bias), the critic is now a *different* model family (Codex). Based on doc 2204 / 99darwin/orchestrator pattern (MIT, credited). Flat-rate pricing, no OpenRouter.

**Impact:** The organism's core loop now has four new verification layers. This is the "march of nines" principle (loop-evals.md) applied internally to ZOE itself.

### Rules: Credit Attribution + Pre-Merge Security Gate (PRs #2856, #2861)

**Category:** Rules / Infrastructure

Two new permanent operating rules landed today:

- **Credit + attribution (rule, #2861):** Every OSS repo, pattern, skill, or piece of music we build on gets credited — inline at use site, in research docs, in PR bodies. Triggered by the nickysap/99darwin adoption. ZAO is a creator-first org; crediting is the ethos, not just compliance.
- **Pre-merge security gate (rule, #2856):** Born from yesterday's incidents — an anonymous board leak (PR #2829 had no session guard) and a red-main from partial test run (PR #2830 broke a test). Now: before any merge, the auth guard must be read (not summarized — *read*), and the full test suite must pass (not just touched files).

**Impact:** Both rules are in `.claude/rules/` and auto-load every session.
