## Key Captures

### Agent Identity Layer — Three Primitives in One Day

**Category:** Architecture / DreamNet

The three off-chain primitives (ERC-8004 agentcard, agent-receipts, a2a-envelope) give the ZAO swarm a verifiable identity layer without a blockchain:

- **ERC-8004 agentcard:** A standardized identity card per agent — name, capabilities, owner, endpoints. Off-chain JSON, conforming to the draft ERC-8004 spec. Agents can now say "I am ZOE, owned by @bettercallzaal, I do X."
- **Agent receipts:** Every action produces a hash-chained receipt — linked to the previous action, timestamped, signed. This is the audit trail Proof Drops needs. Action → receipt → Proof Drop → funding application.
- **A2A envelope:** When ZOE sends a message to another agent (ZAO Devz, Bonfire, the fleet), that message is now MAC-authenticated. The receiver can verify the sender and that the content wasn't altered in transit.

Together these three form the ZAO's sovereign A2A bus (doc 2212). They're composable: an agentcard identifies the sender, an envelope carries the message, a receipt records that it happened.
