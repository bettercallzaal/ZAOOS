**MINDFUL MOMENT**

CLAUDE.md was wrong about itself.

The number of API routes. The component count. The hook count. The document that orients every Claude session — the one thing that's supposed to be ground truth about this codebase — was working from stale numbers.

There's something worth sitting with here: the most trustworthy things in a system are also the ones nobody double-checks, because they've earned that trust. CLAUDE.md gets read on every session start. Nobody reads it to verify it. It's too authoritative to audit.

That's where drift hides. In the things that look finished. The document that's "already done." The partner relationship that's "already settled." The configuration that "has always been that way."

Two PRs fixed exactly this: a retired partner still in active agent prompts, and a self-description that was quietly wrong. Neither was urgent. Neither would have caused a system failure. But agents running on wrong context build wrong things — slowly, confidently, in the wrong direction.

The discipline is checking the things that feel too established to check. Not constantly. But on the small days, when the sprint is over, when the calendar has a gap. Tuesday is the right day to read the document everyone trusts.
