## Key Findings by Theme

### Theme 1: Silent Features Instrumented (PR #3084)

Nine ZOE features that appeared to run — because they were merged and flagged — were never emitting any observable proof of execution. Instrumented today with `featureRan()` calls on the success path. The check that was supposed to verify this was lying: it was confirming reachability (module loaded), not execution.

**State-claims.md rule in action:** "Merged" ≠ "Running." A feature has four states — BUILT, WIRED, FLAGGED, LIVE — and only the first is visible from the code.

### Theme 2: Research Loop Was Discarding Paid Work (PR #3094 — Critical Fix)

The ZOE research loop was discovering content, doing the work, and then silently discarding results when an intermediate step failed. It was also lying about why — reporting a non-error exit while dropping the payload. Fixed: failed work is now queued (not deleted), and exit codes are honest.

This is the "paying for a turn and getting nothing" failure the agent-spend rule was written about.

### Theme 3: Federation Canary v1 Ships (PR #3079 — Big)

`federation-canary-v1`: terminal states implemented, durable checkpoints, false-green matrix. The DreamNet federation pattern — file upload → receipt ACK → traced checkpoint — is now in a canary that can detect and surface false-green states (reporting success while having accomplished nothing). This is the verifiable proof-of-work pattern for cross-organ federation.

### Theme 4: Backlog Grill Made Resolvable (PR #3085)

The backlog grill had no way to reach zero — it would flag items indefinitely. Fixed: 12-hour cap window + a re-ask tier. `noisy-signal-guard.md` pattern applied: a check that always fires is a check nobody reads.

### Theme 5: ICM Box Partner List Outdated (PR #3098)

Live ICM boxes were still naming partners the ZAO retired. Partners that ended months ago were still getting surfaced as active relationships to every agent that reads the graph. Corrected.

### Theme 6: ZOL Was Silent About Being Broken (PR #3097)

ZOL (Zaal's Output Log, or similar) was in draft-only mode for eleven days. During those eleven days it was reporting hourly — but each report was useless because the output was draft-only and invisible to downstream consumers. Named and fixed. Another silent-failure-guard instance.
