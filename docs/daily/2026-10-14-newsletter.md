**MINDFUL MOMENT**

The /fa command is infrastructure for asking for help. That's a specific kind of thing to build: a tool that exists only to help its operator navigate a system they didn't design, on their behalf, one step at a time. It doesn't make decisions. It holds the thread.

The ZAO builds a lot of infrastructure for doing things. This one is infrastructure for asking. The Fractured Atlas application is a real opportunity — arts grant, community focus, real money. But the form is long and the flow is non-obvious. So the system learns the form and walks through it with you.

There's a pattern here: self-scout checks external systems so ZOE doesn't fall behind. /fa navigates external systems so Zaal doesn't have to hold the full context. Two different tools for the same core problem — being a small builder operating at scale.

The answer to doing more isn't always doing faster. Sometimes it's building the guide.
