## What Shipped

### Organism Architecture: Four Organs in One Sprint

The most significant engineering work of H2 so far. Four organs shipped or finalized this week, turning the organism from a concept into a functional system:

**Control Plane** (`src/lib/control-plane/`) — the operational nervous system. Every organ publishes its identity, version, capabilities, dependencies, health, and metrics to a central registry. Coordination cost is now flat — you don't need to know what's running, you just query the plane. PR #2549.

**Bloodstream** (`src/lib/bloodstream/`) — the circulatory organ. Vacuum Spikes ingest external sources (Farcaster, WaveWarZ, Telegram events), normalize to Observations, enrich, TTL-cache, dedup, and distribute to subscribers. One shared circulatory system — no organ polls the same API twice. PR #2548.

**Eyes** (`src/lib/eyes/`) — pure perception, observe-only. Observation contract + registry + reference sensor.

**Ears** (`src/lib/ears/`) — event listeners that reuse the Observation contract. Dedup + backpressure built in.

Four organs now form a sensory-to-circulatory-to-nervous-system chain. The next layer is Memory.
