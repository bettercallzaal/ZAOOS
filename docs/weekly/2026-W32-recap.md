## Week's Best Idea

**The critic that can't see its own blind spots.**

The week's through-line: a system that criticizes its own output has a structural problem. Same family, same priors, same blind spots. The fix is architectural — route the critic role to a different model family. Codex reviewing ZOE isn't just an extra check; it's a different epistemic position.

This started as a research doc (2204, 99darwin pattern), became code (cross-family critics Thursday), and by Friday it was a full panel with shadow-mode, cost telemetry, and GPT-5.5 escalation. The pattern generalized fast because it's right.

The same idea applies everywhere the ZAO operates: weekly recaps, design reviews, peer feedback. The outside view isn't just independent — it's *differently shaped*.
