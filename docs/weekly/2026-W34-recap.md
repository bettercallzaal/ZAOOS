## What Shipped

**50 commits. 5 days. The week the fleet learned to pay once.**

### The Week's Central Rule: `code-over-inference`

Everything this week orbits one idea Zaal surfaced on Thursday: **AI costs vs. building software that just runs for free.** The measurement was $3,001.85 in one day, $56.64 per PR, from 71 sessions where agent loops were re-deriving things that could have been scripts. The counter-example: `zj`, `zao-wall`, `zao-spend`, `zao-lanes`, `lane-send`, `zao-status-write` — 2,019 lines written once, now free to run forever, unlimited.

The rule (`code-over-inference`, #3222, merged Friday) names the test: *Does this need fresh judgment each time, or the same judgment every time?* Same judgment = script. Fresh judgment = worth the turn. Everything mechanical — counting, parsing, filtering, fetching, formatting, scheduled checks — is a script. Everything with ambiguity, synthesis, grounded code change — that's what the Claude cap is for.
