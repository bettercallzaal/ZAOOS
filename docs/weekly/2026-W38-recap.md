## WHAT SHIPPED THIS WEEK

### ZOE Became an Interface

The biggest shift this week wasn't a feature — it was a feeling. ZOE went from being a text parser to being something you'd actually want to tap. Three PRs, 300+ lines, and the Telegram experience crossed a line:

- **Interactive cockpit keyboard** (#3554) — tappable buttons in the ZOE cockpit. The commands that used to require you to type them now have buttons.
- **Scoped command menus** (#3552) — different menu shapes for different group types. A dev group sees dev commands. An artist group sees what artists need. Onboarding new groups is now frictionless.
- **Privacy isolation** — ZOE no longer bleeds context between chats. The group you're in is the only context ZOE can see in that conversation.
- **Partner escalation bridge** — partners can escalate directly to Zaal through ZOE without Zaal having to explain the whole context.
- **Per-group persona** (#3566) — ZOE is now a different character in different rooms by design. Every group ID read goes through a centralized env.ts routing layer.
- **Non-owner command fence** (#3567) — a non-owner typing an owner command gets one short message, once an hour, then nothing. The bot stops barking.

### Autopilot Got a Constitution

- **ADR-004: autopilot acts on reversible work and stops at the one-way doors** (#3550) — The rule is now written. Autopilot never takes irreversible actions autonomously. Knowing exactly where the circuit breaker is means you can trust everything this side of it.
- **ADR-003 (proposed): failure sends declare their class at the sink, not by lint** (#3548) — Still open for discussion but the shape is right.
- **Autopilot dispatcher dry-run** (#3543) — Can now preview which cards it would take before it takes them.
- **One-way doors as data** (#3542) — The list of irreversible actions is now a data structure, not a comment.

### ZOE Observability + Reliability

- **ZOE alarm when repo-improver pipeline can't run** (#3538)
- **Scheduled needs-zaal digest** (#3539) — At 08:00 and 20:00 ET, with the recommended action first.
- **Send log records every delivered send** (#3547) — Not just blocks. Every send.
- **ZOE pulls vault before reading, shows copy age** (#3560, open) — How old is ZOE's copy of the vault? Now it tells you.
- **Ingest inbound media to vault at inbox/-/** (#3541) — Media that comes in through ZOE gets stored in the vault with pre-commit screening.
- **Discord replies scoped like Telegram groups** (#3565) — Parity across platforms.

### Knowledge Infrastructure

- **Doc 2500: ZAOOS rules reach 1 of 45 repos** (#3559) — The finding: 37 rules built from six months of hard lessons live only in ZAOOS. Forty-four other repos in the estate don't have them. The doc has a path forward.
