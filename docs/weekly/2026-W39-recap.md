## WHAT SHIPPED THIS WEEK

### The Research Library Kept Saving Builds

Week 39's loudest signal wasn't a shipped feature — it was a pattern that showed up three separate times: the capability we thought we needed to build already existed.

- **Orca/Antigravity bridge** (doc 2543) — A session analysis said we needed to build safety primitives before Antigravity could drive Claude Code sessions. The primitives already existed in the Orca CLI as first-class commands: `orca terminal wait --for tui-idle` and `orca terminal send --wait-submit`. No build needed. Antigravity → Claude Code is operational today.
- **Bot fleet consolidation** (doc 2541) — The "ZOE vs ZAOstock bot upgrade" question was a false choice. ZOE and the ZAOstock bot are the same codebase in `ZAOOS/bot/src/`. The `bettercallzaal/zaostock-bot` copy has diverged (708 vs 361 lines, running from a non-git dir with hand patches), but the source of truth is clear. The consolidation from doc 688 (May 2026) was recommended and never executed. That's the task.
- **Stripe Buy Button** (doc 2542) — The white-card styling mismatch on `/tickets` and `/donate` looked like a CSS problem. It's a Stripe dashboard setting, baked into the buy-button-id at generation time. Shadow DOM. No CSS from the embedding page can reach it. Fix is one "Customize" click in the Stripe dashboard. Not a code change.

The library is functioning as designed: you find things, document them, and six months later when the question comes back from a different angle — you read what you already know instead of re-deriving it.
