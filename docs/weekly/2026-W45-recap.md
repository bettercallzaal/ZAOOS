## WHAT SHIPPED

### ZOE got group-chat intelligence

The two biggest ZOE items from the behavior spec both landed this week:

**#4239 - Group-chat rules in community block.** ZOE now surfaces the community rules inline when someone is in a group chat. New member asks a question, ZOE can orient them without Zaal having to do it manually. This was item 163. It's been on the list for months.

**#4238 - Engaged window is chat-wide.** ZOE's attention window now spans the full conversation instead of just individual reply threads. Pairs with #4239 - now ZOE understands the room, not just the message.

Both are live.

### ZOE routing got smarter

**#4244 - Delegation + decompose detectors fix.** When a message is a quote-reply, ZOE was reading the wrapper instead of the inner reply. Now it reads the actual thing someone wrote. Small fix, real correctness improvement.

**#4245 - OpenRouter opt-in.** ZOE can now route through OpenRouter for text tasks, behind the `ZOE_OPENROUTER_RUNG` flag. Off by default. The flag exists now and can be enabled without a code change.

### Infrastructure

**#4248 - Credit attribution: standing licence rule.** Permissive licences (MIT, Apache-2.0, BSD, MPL-2.0) now pass without a per-PR call to Zaal. GPL, AGPL, unclear, or no licence still need him. Clears a lot of friction on research PRs.

**#4240 - no-rm-rf evaluator carve-out merged.** The evaluator lane can now clean up its own evict-plan directories. This was the same change as the held #4120 (Oct 22) - #4240 is the clean re-cut on main. #4120 is now superseded.
