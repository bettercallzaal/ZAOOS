## WHAT SHIPPED THIS WEEK

### ZOE Gets Auditable

This was the week ZOE stopped being a system you hope is working and became one you can verify. Three features shipped back to back, all behind flags, all waiting for a flip:

**Failure memory (#4294, #4299).** ZOE workers now start each task knowing their recent failures, framed as records rather than raw error dumps. The fix strips backticks, handles non-string errors, makes the failure readable. When a build fails twice in the same spot, ZOE now knows why.

**Research critic (#4297).** Every URL cited in a ZOE research doc now gets fetched. A dead link kills the doc. This closes the fabricated-citation loop that's been a known gap since doc 2250. No more passing a doc with invented sources.

**Haiku model-tier classifier (#4301, ZOE_MODEL_CLASSIFIER).** The ZOE concierge can now route simple queries to Haiku. At scale, most questions don't need Opus or Sonnet. This is a cost routing feature that also makes ZOE feel faster on the cheap answers.

**Concierge golden set (#4293).** ZOE now has a real test suite with a scorer. The first run gives a baseline; now every change to the concierge can be measured against it.

### Hermes Gets Disciplined

**Write-set enforcement (#4295, #4296).** A Hermes build can only touch the files it declared in its write-set. The forbidden-path check was extended to catch new files too, not just edits. Builds that go off-script now fail loudly.

### ZAO Runs a Node

Doc 643, updated three times on Thursday: **ZAO is running its own Hypersnap read node.** Upgraded to 0.17.5 for the Nov 12 fork. Bootstrap-peer fix for read nodes documented. The decision is read node over validator - no token rewards, cost-benefit doesn't close for a full validator seat. But this is data sovereignty on Farcaster's social graph. ZAO can query its own slice of the network without going through haatz.quilibrium.com.

### papertrailOS Fork: Green Light

Doc 2734 updated Nov 10: the papertrailOS licence landed. The fork can start on Zaal's word. This was blocked on licensing for weeks. It's unblocked now.
