# 2108 - TVU One IRL streaming backpack - fit + the cheaper-first call

> **Goal:** Assess the TVU One (a broadcast-grade IRL streaming backpack) for ZAO's livestream-every-festival goal, and give an honest buy/skip against ZAO's bootstrapped budget.

## Recommendation first

**Do NOT buy TVU One yet.** It's genuinely excellent hardware, but it's broadcast-enterprise gear (no public price = quote-based = expensive), and ZAO's IRL streaming need (festivals, COC, fractals) can be met at a fraction of the cost today. **Start with phone + Restream (already the ZAO default) + a consumer bonding option (LiveU Solo / Peplink) if a single connection proves unreliable.** Reserve TVU-grade only if a flagship event (ZAOstock, Oct 3) needs guaranteed broadcast reliability and there's a sponsor/budget to justify it.

## What TVU One is (specs, verified from the page)

An all-in-one IRL streaming backpack:
- **6 built-in global 5G modems, up to 12 aggregated connections** (incl. WiFi + Ethernet), using ISX cellular bonding for dynamic network adaptation - the core feature: reliable uplink from anywhere by bonding many connections.
- **0.3 second latency** (near-real-time).
- **Hot-swappable batteries** - continuous streaming through long events, no interruption.
- **One-click multi-platform broadcasting** + 24/7 dedicated support.
- "Ditch external modems" - the whole rig is self-contained.

## The honest gaps

- **No public price.** TVU is a broadcast/enterprise vendor; TVU One is quote-based, which in this category means multiple thousands of dollars up front, and cellular bonding rigs typically carry **ongoing data/subscription costs** (per-modem SIM data + often a service tier). Budget accordingly - and get the actual quote + data-plan structure before considering it. (The page lists no weight, encoding, or max resolution either - ask.)
- **Overkill for the current stage.** ZAO events are community-scale and bootstrapped. 6-modem broadcast bonding solves a reliability problem you mostly don't have yet at a price that's hard to justify pre-sponsor.

## Where it WOULD fit ZAO

The need is real and recurring: ZAO wants to **livestream all festivals** (doc 2101, the Fractal call) - ZAOstock (Oct 3), COC Concertz, fractals, WaveWarZ IRL. DCoop's Festival 3 recap flagged connectivity/sound as the biggest homegrown-show obstacle. A bonding backpack solves the *connectivity* half: reliable uplink from a park/venue with no dependable WiFi. So TVU-class gear is the *right category* - just not the right *price point* until a flagship event + sponsor justifies broadcast reliability.

## Cheaper-first ladder (ZAO-appropriate, cheap -> premium)

1. **Phone + Restream** (already the ZAO default streaming surface) - free/low-cost, multi-platform. Good enough for most fractals/workshops on decent 5G.
2. **Consumer bonding** if single-connection drops at venues: **LiveU Solo** or a **Peplink** bonding router (roughly ~$1k class, plus SIM data - verify current pricing). Bonds 2-3 connections; covers the 80% reliability case at ~10-20% of TVU cost.
3. **TVU One / broadcast bonding** - only for a flagship, sponsor-backed event where a dropped stream is unacceptable.

This ladder matches ZAO's cheap-first, OSS-leaning ethos: spend the minimum that streams the event reliably, escalate only when the event's stakes (and budget) rise.
